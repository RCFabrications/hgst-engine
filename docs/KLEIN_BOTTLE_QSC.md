# The Klein-Bottle Homological Quantum Stabilizer Code (K-QSC)

Constructs non-orientable topological quantum error-correcting codes over the Galois field $\mathbb{F}_2$.
While $H_2(K^2; \mathbb{Z}) = 0$, the manifold is canonically orientable over $\mathbb{F}_2$, yielding an exact $[[27, 2, d]]$ CSS stabilizer code with built-in $\mathbb{Z}_2$ Möbius parity-inversion protection.
